# Dernek Yazılımı logo dosyaları

- logo.svg: açık zeminler için yatay yazılı logo.
- logo-acik.svg: koyu zeminler için açık renk yazılı logo.
- simge.svg: avatar, uygulama simgesi ve favicon için kare işaret.

SVG dosyaları gerçek vektördür, yazılar path'e dönüştürülmüştür. Font kurulumu veya harici dosya gerektirmez. Yazılı logoların arka planı şeffaftır; simgenin yeşil karesi tasarımın parçasıdır.

Ana renk: #173e33. Vurgu: #d9ed96. Açık renk: #f8f9f4.
Oranları koruyarak ölçeklendirin ve çevresinde en az simge genişliğinin dörtte biri kadar boşluk bırakın.

PNG sürümleri: logo.png ve logo-acik.png 2400 piksel genişliğinde; simge.png 1024×1024 pikseldir. SVG kaynaklarından doğrudan oluşturulmuştur; arka plan şeffaftır.
