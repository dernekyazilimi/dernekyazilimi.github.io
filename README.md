# Dernek Yazılımı tanıtım sitesi

https://dernekyazilimi.github.io/

Türkçe, mobil uyumlu statik tanıtım sitesi. Derleme adımı, JavaScript veya harici font bağımlılığı yoktur. Arayüz illüstrasyonu temsilidir; gerçek kişi verisi içermez.

## Yerel önizleme

Bu dizinde `python3 -m http.server 8080` çalıştırıp http://localhost:8080 adresini açın.

## Yayın

GitHub Pages, `main` dalının kök dizininden yayın yapar. `main` dalına gönderilen değişiklikler otomatik yayınlanır. `.nojekyll` dosyası statik dosyaların doğrudan sunulmasını sağlar.

## İçerik

- `index.html`: içerik ve erişilebilir HTML yapısı
- `style.css`: duyarlı tasarım
- `favicon.svg`: site simgesi
- `robots.txt`, `sitemap.xml`: arama motoru yönergeleri

Uygulama kaynak kodu ve kurulum belgeleri: https://github.com/lkdtr/dernekyazilimi
